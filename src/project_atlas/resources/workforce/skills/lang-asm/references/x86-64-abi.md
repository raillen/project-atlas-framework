# x86-64 System V AMD64 ABI Reference

## 1. Stack Frame Architecture
- The red zone is a 128-byte area below `RSP` that shall not be modified by signal or interrupt handlers (in user space).
- Leaves can use the red zone without adjusting `RSP`, provided they make no further function calls.
- If a function makes a call, it must allocate stack space and ensure `(RSP - 8) % 16 == 0` right before the `call` instruction.

## 2. Floating-Point & SIMD Calling Convention
- Arguments: `XMM0` through `XMM7`.
- Return: `XMM0` (and `XMM1` if complex).
- All `XMM` registers are caller-saved scratch registers.
