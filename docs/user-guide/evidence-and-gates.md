# Evidence and Gates

## Evidence (`schemas/evidence.schema.json`)
Durable or operational proof of verification:
- `test`: Automated test results and logs.
- `build`: Clean build artifacts.
- `benchmark`: Performance profile measurements.
- `security-scan`: SAST/DAST audit logs.

## Gates (`schemas/gate.schema.json`)
Quality and security checkpoints that must pass before task/goal completion.
