# Managing Projects

A Prumo workspace is anchored by `prumo.json` at the repository root.

## Layout
- `prumo.json`: Canonical project and protocol configuration.
- `docs/PRUMO.md`: Central intent and navigation router.
- `PROJECT_STATE.md`: Ephemeral human-facing status.
- `.ai/`: Goals, plans, policies, and workforce manifests.
- `.prumo/`: Derived caches, runtime states, and historical intelligence.
