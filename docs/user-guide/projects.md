# Managing Projects

A Project Atlas workspace is anchored by `atlas.json` at the repository root.

## Layout
- `atlas.json`: Canonical project and protocol configuration.
- `docs/ATLAS.md`: Central intent and navigation router.
- `PROJECT_STATE.md`: Ephemeral human-facing status.
- `.ai/`: Goals, plans, policies, and workforce manifests.
- `.atlas/`: Derived caches, runtime states, and historical intelligence.
