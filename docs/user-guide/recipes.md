# Recipes v2

Recipes (`schemas/recipe.schema.json`) define executable multi-agent workflows.

## Standard Recipes
- `feature-standard`: Feature development with independent review.
- `bug-fix`: Evidence-backed bug reproduction and fix.
- `architecture-change`: Staged ADR-backed architectural refactor.
- `release`: Release gate verification and packaging.
- `security-review`: Threat modeling and vulnerability audit.
- `github-issue`: End-to-end issue triage and authoring.
- `ui-feature`: UX research, wireframing, tokens, and accessible UI.
