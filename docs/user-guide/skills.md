# Skill Packages v2

Skills are modular, reusable capabilities (`schemas/skill.schema.json`).

## Package Structure
```text
skills/<skill-id>/
├── manifest.json   (required)
├── SKILL.md        (required)
├── references/     (optional)
├── templates/      (optional)
├── checks/         (optional)
└── scripts/        (optional)
```
